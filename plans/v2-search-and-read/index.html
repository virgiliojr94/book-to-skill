    Release v2.0 Plan: Search & Read (MCP-Assisted Discovery & Incremental Remote Generation)¶

    Status: ACTIVE EXECUTION PLAN — PR 0–5

    This document is the shared execution state and contract ledger for book-to-skill v2.0 (Search & Read). Every coding or verification agent MUST read this document first, locate its assigned task or the next READY task whose dependencies are DONE, respect file ownership boundaries, obey the frozen interface contracts below, run all validation gates, and record actual command output in the Evidence Ledger before marking any task DONE.

    1. Architectural Invariants (Non-Negotiable)¶

    1. Two input modes, one skill output contract:
    2. Mode 1 — Local (unchanged): File/dir/glob → Python extractor (book_to_skill/) → full_text.txt + metadata.json → Generator (SKILL.md). Must continue working with zero MCP tools and zero optional dependencies (CI/smoke green).
    3. Mode 2 — Search & Read (new): Query (/book-to-skill search ...) → Host Agent calls MCP (search, get_details, read) → Python offline helpers (book_to_skill/remote/) normalize, check policy, sanitize, track cursors/checkpoints, compute coverage/provenance → Incremental chapter generation → Same skill output (SKILL.md, chapters/, glossary.md, patterns.md, cheatsheet.md).
    4. Strict Zero-Network Boundary in Python Core (SECURITY.md):
    5. book_to_skill/ MUST NOT perform outbound HTTP requests, open sockets, embed Go code from libgen-mcp, or require libgen-mcp as a runtime dependency.
    6. The host coding agent invokes MCP tools (search, get_details, read); book_to_skill/remote/ consists purely of deterministic stdlib-only offline helpers operating on JSON/text payloads passed by the agent/CLI/tests.
    7. Keep SKILL.md Lean (Progressive Disclosure):
    8. Root SKILL.md (currently 880 lines) gets only a compact Mode 2 router/trigger and pointer.
    9. Full Mode 2 instructions live in references/search-and-read.md, loaded lazily only when Mode 2 is invoked.
    10. Do not break tests/test_publish_visibility_gate.py (Step 11 --private gate wording must remain intact).
    11. Untrusted External Data & No Permanent Raw Book Storage:
    12. All remote MCP text MUST pass through book_to_skill.sanitize.sanitize_extracted_text() before synthesis or inspection.
    13. Mode 2 MUST NOT save a permanent full_text.txt or download the full book file via download. Raw chapter fragments are discarded after synthesis.
    14. remote_session.json and provenance metadata MUST NEVER persist raw copyrighted prose.
    15. Python 3.9+ Compatibility & Conventional Commits:
    16. Target requires-python = ">=3.9" (from __future__ import annotations).
    17. Do not edit CHANGELOG.md manually; PR titles/commits must follow Conventional Commits.

    2. Frozen Interface Contracts (Zero-Drift Schema)¶

    Agents implementing PR 2, PR 3, PR 4, and PR 5 MUST build to these exact schemas:

    Contract A — NormalizedWorkCandidate (book_to_skill/remote/discovery.py)¶

    Produced by normalizing MCP search / get_details payloads: 

    {
  "provider": "libgen-mcp",
  "item_id": "string",
  "title": "string",
  "authors": ["string"],
  "edition": "string | null",
  "year": "int | null",
  "format": "string | null",
  "language": "string | null",
  "identifiers": {
    "isbn": ["string"],
    "doi": "string | null"
  },
  "source_name": "string",
  "access_info": "string",
  "license_info": "string | null",
  "dedup_key": "string"
}
    - normalize_search_results(raw_results: list[dict], provider: str = "libgen-mcp") -> list[dict] - normalize_work_details(raw_details: dict, provider: str = "libgen-mcp") -> dict - group_duplicate_editions(candidates: list[dict]) -> list[dict] (groups candidates sharing dedup_key while keeping selectable editions explicit).

    Contract B — RemotePolicyConfig & Copyright Gate (book_to_skill/remote/policy.py)¶

    Configurable without rewriting the pipeline (via env var BOOK_TO_SKILL_REMOTE_POLICY JSON/path or explicit dict): 

    {
  "enabled_providers": ["*"],
  "blocked_providers": [],
  "require_explicit_confirmation": true,
  "default_publish_visibility": "private",
  "allow_public_publish": false,
  "warn_mcp_temporary_cache": true
}
    - load_policy(config_override: dict | None = None) -> dict - check_provider_allowed(provider: str, policy: dict) -> tuple[bool, str] - build_access_copyright_notice(candidate: dict, policy: dict) -> str Must display: source/provider, work title/authors/edition/identifiers, known license/access info, explicit statement that user confirmation does not equal copyright-holder authorization, and technical note that MCP read may use temporary server cache / transmit text to the model. - verify_user_confirmation(reply: str, candidate: dict, policy: dict) -> bool (explicit consent required; never inferred).

    Contract C — RemoteReader & RemoteSessionState (book_to_skill/remote/reader.py, checkpoint.py)¶

    Reader step contract (host passes raw MCP read response dicts into Python offline processors): - Supported read modes: "outline", "section", "cursor". - sanitize_remote_chunk(raw_text: str) -> dict returning {"text": str, "removed_invisible_count": int, "empty": bool}. - parse_outline_response(raw_outline: dict) -> tuple[str, list[dict]] -> returns (outline_mode, chapters) where outline_mode is "outline" or "sequential_fallback", and each chapter entry has {"index": int, "section_id": str, "title": str}. - process_section_page(raw_page: dict, *, seen_cursors: set[str], max_cursors_per_section: int = 100) -> dict: - Runs sanitize_extracted_text(). - Detects next_cursor, truncated flags, missing/empty sections, and infinite cursor loops (if next_cursor in seen_cursors or limit reached -> stops with status="incomplete" and explicit reason). - remote_session.json schema inside per-run workdir (chmod 0700, atomic write via temp + os.replace, ZERO raw prose stored): 

    {
  "schema_version": 1,
  "session_id": "string",
  "provider": "string",
  "work": { "item_id": "...", "title": "...", "authors": [], "edition": null, "identifiers": {} },
  "confirmed_by_user": true,
  "outline_mode": "outline",
  "limits": { "max_cursors_per_section": 100, "max_total_requests": 1000 },
  "chapters": [
    {
      "index": 1,
      "section_id": "ch1",
      "title": "string",
      "status": "pending | in_progress | done | incomplete | failed",
      "next_cursor": "string | null",
      "chunks_read": 0,
      "sanitized_removed_count": 0,
      "truncated": false,
      "error_reason": "string | null"
    }
  ]
}
    - Resume contract: pending_chapters(session) skips done chapters without re-reading them; preserves/resumes from saved next_cursor or flags incomplete/failed.

    Contract D — CoverageReport & RemoteProvenance (book_to_skill/remote/coverage.py, provenance.py)¶

    • build_coverage_report(session: dict) -> dict: Returns {"chapters_total": int, "chapters_done": int, "chapters_incomplete": int, "chapters_failed": int, "missing_sections": list, "truncated_sections": list, "completeness_status": "complete" | "partial" | "degraded", "warnings": list[str]}.
    • build_remote_provenance(candidate: dict, session: dict, policy: dict) -> dict: Returns traceable edition/source/identifier/provider metadata + coverage summary, guaranteed free of raw book prose.
